# 2026-07-08

## 启动报错修复：Missing Microsoft.AspNetCore.SignalR.Client.Core

**现象**：`CJDSL.Web` 启动渲染组件时抛 `System.IO.FileNotFoundException: Could not load file or assembly 'Microsoft.AspNetCore.SignalR.Client.Core, Version=10.0.9.0'`，发生在 `ComponentFactory.CreatePropertyInjector` 反射注入属性时。

**根因**：`CJCore.Modules.SignalR`（外部框架仓库 `D:\Pro\CJ.Plug.Github\CJCore` 的 RCL）引用了 NuGet 包 `Microsoft.AspNetCore.SignalR.Client`（→ 依赖 `.Client.Core`）。但 SignalR **客户端**程序集**不属于** `Microsoft.AspNetCore.App` 共享框架（已核对本机 9.0.17 / 10.0.9 共享框架目录，仅有服务端 `SignalR.dll`/`Core`/`Common`/`Protocols.Json`，无 Client 程序集），必须作为独立包随应用部署。
`CJDSL.Web` 是经 `CJCore.Framework` 多层间接引用到该模块的，客户端包未被传播进 `CJDSL.Web` 的依赖闭包（deps.json 无记录、NuGet 缓存最高仅 10.0.8），运行时按 10.0.9.0 解析失败。

**修复**：
- `Directory.Packages.props` 新增中央版本 `<PackageVersion Include="Microsoft.AspNetCore.SignalR.Client" Version="10.0.9" />`。
- `src/CJDSL.Web/CJDSL.Web.csproj` 新增直接 `<PackageReference Include="Microsoft.AspNetCore.SignalR.Client" />`（直接引用不被 SDK 当作"共享框架已提供"而抑制）。

**验证**：`dotnet build` 0 错误；`bin/Debug/net10.0/` 出现 `Microsoft.AspNetCore.SignalR.Client.dll` + `.Client.Core.dll`；deps.json 记录 `Microsoft.AspNetCore.SignalR.Client/10.0.9` 与 `.Client.Core/10.0.9`。

**经验**：外部框架 RCL 间接带来的 `Microsoft.AspNetCore.*` 客户端类包（SignalR.Client / HttpClientFactory 等）若不在共享框架内，需在消费方 Web 项目显式直接引用，否则运行时缺程序集。
