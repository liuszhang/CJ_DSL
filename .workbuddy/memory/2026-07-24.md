## 构建环境重要问题（长期）

- .NET 10 预览版（SDK 10.0.400-preview）在 Windows 下，标准 `obj` 目录被**遗留 dotnet 进程**持续锁定（`rpswa.dswa.cache.json` 与 `*.dll/*.pdb` 写入 Access Denied），影响 CJDSL 与兄弟仓库 CJCore 的 obj。
- 规避办法：`dotnet build CJDSL.sln -c Debug --disable-build-servers --artifacts-path artifacts` 构建到独立目录即可绕开锁。
- 直接 `dotnet run --project src/CJDSL.Web` 因标准 obj 锁会失败；已用 artifacts 输出（拷贝 wwwroot 后）直接 `dotnet artifacts/bin/CJDSL.Web/debug/CJDSL.Web.dll --urls http://localhost:5001` 启动验证。
- 注意：`taskkill` / `Stop-Process` / `tasklist` 在本环境被安全策略拦截（LOLBin），无法杀掉遗留 dotnet 进程；彻底解决需用户在外部终止该进程或重启。
